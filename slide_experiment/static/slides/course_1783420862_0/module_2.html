AI Fundamentals: Data as Fuel

  • AI requires data to function, much like a car needs fuel.
  • Data includes facts, numbers, or items, categorized as structured or unstructured.
  • Structured data is highly organized (e.g., Excel spreadsheets).
  • Unstructured data includes photos, emails, and videos. [IMAGE: img_24]
  • AI performance hinges entirely on input data quality ('Garbage in, garbage out').

Programming Paradigms: Rules vs. Learning

Option A

  • Traditional: Relies on humans writing strict, predefined rules for the computer.

Option B

  • Modern: Machine Learning autonomously determines rules by analyzing vast amounts of data.

Machine Learning Paradigms

Supervised Learning

Uses labeled data where the correct output is known during training.

Example

Training AI with 10,000 house photos paired with their selling prices.

Unsupervised Learning

Finds hidden structures and patterns within raw, unlabeled datasets.

Example

Clustering users based on similar music listening habits.

Advanced AI Learning Paradigms

Reinforcement Learning

Training AI via rewards and penalties.

Deep Learning

An advanced specialization within Machine Learning.

Deep Learning & Neural Networks

  • Artificial Neural Networks (ANNs) mimic the structure of the human brain.
  • Neural networks function as digital assembly lines using filters. [IMAGE: img_23]
  • Initial layers detect basic features like lines and edges.
  • Subsequent layers build complexity, recognizing shapes (e.g., eyes, noses).
  • The final layer identifies highly complex patterns, such as complete faces.
