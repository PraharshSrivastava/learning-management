The Automated Onboarding Workflow

1

Path Selection Initiated

CRM prompts the user to select one of the defined onboarding paths.

2

eKYC Link Generation

The system automatically generates a unique eKYC link immediately following path selection.

3

Seamless Distribution

The link can be sent directly from the CRM via Email or WhatsApp, eliminating manual handoffs.

4

Automated Account Opening

Client completes the process using the link, and their account is opened automatically by the system.

Key Takeaway: Streamlining Conversion & Onboarding

Manual Handoff (Old Way)

  • Requires manual transfer of information.
  • Risk of delays and errors.
VS

Automated Workflow (New Way)

  • Direct link generation from CRM.
  • Instantaneous distribution via Email/WhatsApp.
  • Automatic account opening upon completion.
