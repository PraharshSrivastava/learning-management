Module Overview: Managing Tasks, Notes, and Daily Activities

  • This module guides you through managing actionable items (Tasks), capturing context (Notes), and logging time spent (Daily Activities).

Creating and Managing Tasks

1

Initiating a Task from a Lead

Open any lead record and navigate to the 'Tasks' section to create a new task.

2

Setting Deadlines and Visibility

Tap 'New Task' to assign a due date, which automatically adds the task to the 'Today's Due Tasks' widget on the dashboard.

3

Standalone Task Creation

Tasks can be created independently of a specific lead for internal follow-ups.

Capturing Context with Notes

  • Notes are created within a lead's record under the 'Notes' section.
  • Input options include typing text or using the microphone to record a voice note.
  • Recorded voice notes are saved and playable directly within the note record.
  • Note playback constraint: Only one voice note can play at a time within the note record.
  • Text comments can be added to a note *after* a voice note has been saved.

Efficient Lead Searching

Search Input Method

  • Type any part of a lead's name (first, last, or middle).
VS

Search System Behavior

  • The system intelligently ignores salutations (e.g., Mr., Mrs.) during the search process.

Tracking Time with Daily Activity Logs

  • Daily Activity logs time-based work performed.
  • Access to Daily Activity logs is available exclusively on the web application via the 'Reports' menu.
  • Important Limitation: Daily Activity tracking is not available on the mobile version in the current release.

Summary of Key Features

Tasks

Create from leads or standalone; set due dates for dashboard visibility.

Notes

Support text and voice recording; sequential playback of voice notes.

Search

Flexible name search that bypasses salutations.

Daily Activity

Time logging feature available only on the web app under Reports.
