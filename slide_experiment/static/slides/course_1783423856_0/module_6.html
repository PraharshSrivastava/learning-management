The most critical skill for the AI era.

Warning: Prompting AI Ineffectively

Avoid Vague Prompts

Do not treat AI like a search engine with vague prompts to achieve optimal results.

Guiding the AI

Set Context

Provide background information to guide the AI.

Define Goals

Establish clear objectives to direct the AI's output.

R-C-T-F Formula

Define Role

Specify the AI's identity, such as 'Act as a fitness coach.'

Structure Prompt

Use the Role + Context + Task + Format formula for effective prompts. [IMAGE: img_43]

Prompt Formula Pillars

Set Context

Provide necessary background information, such as 'I am a busy office worker.'

Define Task

Clearly state the objective you want the AI to achieve, like 'Create a 5-day workout plan.'

Specify Format

Detail the desired output structure, such as 'In a markdown table.'

Refining AI Outputs

Guide With Examples

Use specific examples to direct the AI's desired output style.

Iterate For Quality

Continuously refine responses through iteration to achieve better results.

Seek Clarification

Instruct the AI to request clarification when it is uncertain about details.
