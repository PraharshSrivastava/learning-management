Warning: AI Communication Pitfall

Avoid Vague Input

Structuring High-Quality Prompts

Define Context

Provide necessary context and clear instructions to guide the AI toward better responses.

Apply Formula

Utilize the Role + Context + Task + Format formula for structuring effective prompts. [IMAGE: img_43]

Deconstructing the R+C+T+F Formula

Define AI Role

Specify the AI's identity, such as 'fitness coach.'

Set Context

Provide background information, like 'busy office worker wanting to lose 5kg.'

State Task

Clearly state the specific request, such as 'create a 5-day workout plan.'

Specify Format

Detail the desired output structure, like 'markdown table with columns.'

Refining AI Outputs

Guide Output Style

Provide specific examples to direct the AI's desired output style.

Adjust Output Length

Refine results by requesting specific changes, such as shorter or more casual versions.

Demand Clarification

Instruct the AI to proactively ask for clarification when it is unsure about details.
